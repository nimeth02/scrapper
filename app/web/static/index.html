Hashtag map Checking the graph database…

The agent searches the seed hashtag, reads the other hashtags in those posts and adds the related ones to a graph stored on this machine. Then it goes hashtag by hashtag: every hashtag it searches links to the hashtags already in the graph and brings new ones, until the graph has the node limit or the searches are used up. A hashtag's count is how many collected posts, found by searching other hashtags, carry it. Each search is one or two requests to Instagram.
